## Cómo Ejecutar Este Proyecto

### Requisitos Previos

- Node.js 22.12.0 o superior
- npm (incluido con Node.js)

### Pasos de Instalación

#### 1. Clonar el repositorio

```bash
git clone https://github.com/viccichithiago-dev/portfolio.git
cd portfolio
```

#### 2. Instalar dependencias

```bash
npm install
```

#### 3. Ejecutar en modo desarrollo

```bash
npm run dev
```

La aplicación estará disponible en: `http://localhost:4321`

#### 4. Compilar para producción

```bash
npm run build
```

Los archivos compilados se generarán en la carpeta `dist/`

#### 5. Previsualizar build

```bash
npm run preview
```

### Comandos Disponibles

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Inicia el servidor de desarrollo |
| `npm run build` | Compila el proyecto para producción |
| `npm run preview` | Previsualiza el build localmente |
| `npm run astro check` | Verifica tipos y errores |

## Motivación

Este proyecto de portafolio nació con el objetivo de presentar mi trabajo como desarrollador backend de una manera profesional y accesible. Busqué crear un espacio donde potenciales empleadores, colaboradores y otros desarrolladores puedan conocer mi trayectoria, habilidades y proyectos.

Los objetivos principales de este portafolio fueron:

1. **Presentar mi trabajo**: Mostrar de manera clara los proyectos en los que he trabajado y las tecnologías que domino.

2. **Demostrar habilidades**: Utilizar herramientas modernas como Astro y Tailwind CSS para crear un sitio rápido, responsivo y con buena experiencia de usuario.

3. **Facilitar el contacto**: proporcionar una forma sencilla de contactarme para oportunidades laborales o colaboraciones.

4. **Aprendizaje continuo**: Este proyecto también fue una oportunidad para practicar y mejorar mis habilidades en desarrollo frontend, complementando mi experiencia principal en backend.

Este portafolio representa mi compromiso con la calidad y mi pasión por construir soluciones que marquen la diferencia. Espero que explore mi trabajo y pueda contactarme si tiene alguna consulta o propuesta.
